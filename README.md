# Clinic Portal WordPress Plugin

A WordPress plugin that adds a medical clinic portal to any site. Built to pair with the [Clinic Care](https://github.com/Rentrophic/clinic-care) theme.

## Features

- Physician directory and departments
- Appointment booking
- Patient registration with automatic age calculation
- Staff dashboard for viewing patients
- FAQ, announcements, and contact page
- Crisp live chat integration

## Installation

1. Copy the `clinic-portal` folder into `wp-content/plugins/`.
2. In WordPress, go to Plugins and activate **Clinic Portal**.

Used in the [CareWell Medical Clinic](https://github.com/Rentrophic/carewell) website.
